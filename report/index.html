仿真与实现说明

设备规则（违规即抛错）

  • 擦除只能整块，擦除前块内必须无已编程页
  • 每页每次擦除周期只能编程一次
  • 块内页只能按递增偏移编程，空洞不可回填
  • 坏块（出厂 / 使用中）拒绝一切编程与擦除
  • 多平面编程必须落在同一超块对、同一页偏移

掉电模型

  • 以 NAND 操作为单位；被选中的那一次操作可能整体丢弃、只落一半（多平面）、或页标签损坏
  • 恢复只依赖扫描页标签与保留区记录，不依赖“正常关机”

FTL 结构

  • 页级映射表常驻内存，另在保留区按双 Bank 轮转写快照
  • 快照带 CRC 与提交页；重启先从最新有效快照加载，再回放更新的页
  • GC 先搬有效页再擦除，拷贝获得更高序号，掉电中途原件仍可用
  • 块内偏移 0 存擦除标记（含擦除次数），重启后擦除计数不丢
  • 丢弃通知先落盘再撤映射，回收时不搬运被丢弃的页
  • 双平面：两条主机写可合并为一次多平面编程；GC 拷贝同样成对下发
